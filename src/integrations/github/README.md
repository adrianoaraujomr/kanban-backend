# API com GitHub

- Guia rápido [[1]](https://docs.github.com/pt/rest/quickstart?apiVersion=2022-11-28&tool=curl)

## Autenticação

- No painel do github gerar um token de acesso [[2]](https://docs.github.com/pt/rest/authentication/authenticating-to-the-rest-api?apiVersion=2022-11-28)
- Passar o token gerado no header `Authorization` da requisição com o formato `Bearer {token}`

## Issues

- Ajustar permissões, selecionar repositorios e dar acesso de read e write na parte de issues [[3]](https://docs.github.com/pt/rest/authentication/permissions-required-for-fine-grained-personal-access-tokens?apiVersion=2022-11-28#organization-permissions-for-issue-types)
- Endpoints do Issues [[4]](https://docs.github.com/pt/rest/issues/issues)
